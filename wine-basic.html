WINE BASIC

ワインの超基礎

「どんなワインか」を、自分の言葉で伝えるために。

ワインについて、最初からすべてを覚える必要はありません。

まずは「どんな種類があるのか」「味わいをどう表現するのか」を知ることから始めましょう。

「すっきりした白ワインです」
「香りが華やかなタイプです」
「渋みが穏やかで、軽やかな赤ワインです」

そんな一言で、お客様が選ぶお手伝いをできるようになることが、このページの目標です。

WINE BASIC

1．そもそも、ワインとは？

ワインは、ブドウの果汁を発酵させて造るお酒です。

発酵とは、酵母という微生物が、ブドウに含まれる糖分をアルコールなどに変えることです。

ブドウジュースとワインの大きな違いは、この発酵を経ていることにあります。

同じブドウから造るお酒でも、使うブドウの種類、育つ場所、造り方によって、香りや味わいは変わります。

まずは、次のように分けて考えてみましょう。

品種は「どんなブドウを使っているか」。
生産国・産地は「どこで造られているか」。
味わいのタイプは「どんな特徴を持つワインか」。

この3つを分けて覚えると、ワインリストの情報も整理しやすくなります。

WINE BASIC

2．赤・白・泡・ロゼ・オレンジの違い

ワインの違いを理解するポイントのひとつが、ブドウの皮を、果汁と一緒に使うかどうかです。

赤やロゼの色は、主にブドウの皮から生まれます。

皮からは色だけでなく、渋みのもとになる成分も出てきます。

赤ワイン｜黒ブドウを、皮と一緒に発酵させる

黒ブドウとは、皮が赤紫色や黒紫色をしたブドウのことです。

赤ワインは、主にこの黒ブドウの果汁を、皮と一緒に発酵させて造ります。

そのため、皮の色や渋みがワインに移ります。

ただし、赤ワインがすべて濃厚で渋いわけではありません。

軽やかなものから、しっかりした飲みごたえのあるものまで、さまざまなタイプがあります。

白ワイン｜主に白ブドウの果汁を発酵させる

白ブドウとは、皮が黄緑色や黄色をしたブドウのことです。

白ワインは、一般的にブドウを搾り、皮や種を取り除いた果汁を発酵させて造ります。

造り方によっては、黒ブドウから白ワインを造ることもできます。

すっきり爽やかなタイプだけでなく、香りが華やかなものや、まろやかでコクのあるものもあります。

泡｜炭酸のあるワイン

「泡」は、スパークリングワインのことです。

ワインに溶け込んだ二酸化炭素によって、シュワシュワとした泡が生まれます。

白だけでなく、ロゼや赤のスパークリングワインもあります。

シャンパーニュは、泡の仲間

シャンパーニュは、フランスのシャンパーニュ地方で、定められた条件を満たして造られるスパークリングワインです。

「高いスパークリングワインならシャンパーニュ」というわけではなく、産地や造り方の条件がある名称です。

ロゼワイン｜黒ブドウから造る、ピンク色のワイン

ロゼは、主に黒ブドウの皮から短い時間で色を取り出して造る、ピンク色のワインです。

赤ワインほど濃い色になる前に果汁を皮から離すことで、淡い色合いに仕上げます。

「ピンク色だから甘い」とは限りません。

ロゼにも辛口から甘口まであり、色だけで甘さを判断することはできません。

オレンジワイン｜白ブドウを、皮と一緒に発酵させる

オレンジワインは、白ブドウの果汁を皮と一緒に発酵させて造るワインです。

果物のオレンジから造るお酒ではありません。

皮と接することで、オレンジ色や琥珀色の色合い、渋み、厚みのある口当たりなどが生まれます。

色の濃さや渋みの強さは、造り方によって異なります。

覚えるときは、「白ブドウを、赤ワインに近い造り方で仕上げたワイン」と考えると整理しやすくなります。

WINE BASIC

3．味わいを伝える、基本の言葉

甘口・辛口｜「甘さ」の違い

ワインの甘口・辛口は、主にワインに残っている糖分による甘さの違いです。

甘口は、甘さを感じるタイプ。
辛口は、甘さをほとんど感じないタイプ。

ブドウの糖分が発酵によってどのくらいアルコールに変わり、どのくらい残るかが、甘さに関わります。

ワインの「辛口」は、唐辛子のように辛いという意味ではありません。

また、「渋い」「アルコールが強い」という意味でもありません。

酸味｜レモンや青リンゴを思わせる、すっぱさ

酸味は、口の中に唾液が出てくるような、すっぱさです。

レモンや青リンゴをイメージすると分かりやすく、ワインでは爽やかさや、すっきりした印象につながります。

接客では、商品に合わせて「酸味が強いです」だけでなく、「爽やかな酸味があります」「すっきりした味わいです」と伝えてみましょう。

渋み｜濃くいれたお茶を飲んだときのような感覚

渋みは、口の中がキュッと引き締まったり、少し乾いたように感じたりする感覚です。

濃くいれた紅茶をイメージすると分かりやすく、この感覚に関わる成分をタンニンと呼びます。

ワインのタンニンは、ブドウの皮や種などに由来します。

酸味の「すっぱい」と、渋みの「口がキュッとする」は、別の感覚として覚えましょう。

軽い・しっかり｜「飲みごたえ」の違い

ワインを口に含んだときに感じる、重さや厚み、ふくらみをボディと呼びます。

水のさらっとした口当たりと、生クリームの厚みのある口当たりを比べるように、液体が口の中でどのくらい重く感じられるかをイメージしてみましょう。

軽いワインは、さらっと軽快な印象。
しっかりしたワインは、厚みがあり、飲みごたえのある印象。

ボディには、アルコール分や糖分、タンニンなどが関わります。

「渋みが強いほど必ずフルボディ」「軽いワインなら必ず低アルコール」とは限りません。

フルーティー｜果物を思わせる香りや風味

「柑橘のような香り」「桃のような香り」「イチゴのような香り」など、ワインには果物にたとえられる香りがあります。

これは、その果物が入っているという意味ではなく、ブドウや発酵などから生まれる香りを、身近なものにたとえた表現です。

ここで大切なのは、「フルーティー＝甘口」ではないこと。

果物の香りが豊かでも、糖分による甘さがほとんどない辛口のワインはあります。

香りと甘さは、分けて考えましょう。

例えば、こんな説明ができます。

「香りは華やかですが、味わいは甘さの少ない辛口です。」

WINE BASIC

4．当店の白ワインは、3つのタイプで覚える

私たちのお店では、白ワインをリフレッシング・アロマティック・リッチの3タイプで整理しています。

リフレッシング｜すっきり、爽やか

覚える言葉は、「フレッシュ」「清涼感」「柑橘」です。

爽やかさや、すっきりした印象を伝えたいときのタイプとして覚えましょう。

お客様への伝え方

「すっきり爽やかな白ワインがお好みでしたら、こちらがおすすめです。」

アロマティック｜香りが華やか

覚える言葉は、「フルーティー」「華やか」「豊かな香り」です。

まずは、香りの豊かさが魅力のタイプとして覚えましょう。

お客様への伝え方

「香りが華やかな白ワインがお好みでしたら、こちらはいかがですか？」

香りが華やかでも、必ず甘口とは限りません。

おすすめする商品の甘さは、別に確認して伝えましょう。

リッチ｜まろやか、コクがある

覚える言葉は、「芳醇」「まろやか」「満足感」です。

口当たりのふくらみや、しっかりしたコクを伝えたいときのタイプとして覚えましょう。

樽を使った造り方によって、バニラやトーストを思わせる香りを持つものもあります。

ただし、リッチな白ワインのすべてが、強い樽の香りを持つわけではありません。

お客様への伝え方

「まろやかで、コクのある白ワインがお好みでしたら、こちらがおすすめです。」

3タイプは「特徴」で覚える

この3つは、軽い順や高級な順として覚えるのではなく、「そのワインのどんな魅力を伝えたいか」で整理しましょう。

同じブドウ品種でも、産地や造り方によって味わいは変わります。

品種名だけで分類を決めず、実際の商品リストで確認することが大切です。

5．赤ワインは、飲みごたえの3タイプで覚える

当店の赤ワインは、ライト・ミディアム・フルの3タイプを目安にします。

ライト

軽快で、なめらかな口当たり。

お客様への伝え方：

「軽やかな赤ワインです。」

ミディアム

ほどよい飲みごたえとバランス。

お客様への伝え方：

「ほどよいコクのある赤ワインです。」

フル

厚みがあり、力強い飲みごたえ。

お客様への伝え方：

「しっかりした赤ワインです。」

お客様に好みを聞くときは、

「軽やかなものと、しっかりしたものでは、どちらがお好みですか？」

という聞き方から始めてみましょう。

「渋みは少なめがよい」などのお話があれば、ボディとは別に、そのご希望も確認して選びます。

WINE BASIC

6．まず覚える、白・赤それぞれ3つの代表品種

品種とは、ブドウの種類のことです。

白ワインの代表3品種

シャルドネ｜造り方によって、さまざまな表情を見せる

柑橘や桃などを思わせる風味があり、すっきりしたものから、樽を使ったまろやかで厚みのあるものまで、幅広いスタイルになります。

最初に覚える一言：造り方によって、すっきりにも、まろやかにもなる品種。

ソーヴィニヨン・ブラン｜柑橘やハーブのような、爽やかな香り

柑橘やハーブを思わせる香りと、爽やかな酸味が特徴の品種です。

産地や造り方によって、香りの強さや果実の印象も変わります。

最初に覚える一言：柑橘やハーブのような香りがある、爽やかな品種。

リースリング｜華やかな香りと、はっきりした酸味

花や柑橘、桃などを思わせる香りがあり、酸味がはっきりしている品種です。

辛口から甘口まで造られるため、「リースリング＝甘口」と覚えないことが大切です。

最初に覚える一言：香りが華やかで、酸味があり、辛口も甘口もある品種。

赤ワインの代表3品種

カベルネ・ソーヴィニヨン｜しっかりした渋みと飲みごたえ

カシスなどの黒い果実を思わせる香りがあり、しっかりした渋みや飲みごたえが出やすい品種です。

最初に覚える一言：黒い果実の香りと、しっかりした味わい。

メルロー｜まろやかで、なめらかな口当たり

プラムやチェリーなどを思わせる香りがあり、なめらかな口当たりと、比較的親しみやすい渋みが特徴の品種です。

最初に覚える一言：果実の風味があり、まろやかでなめらか。

ピノ・ノワール｜赤い果実の香りと、軽やかさ

イチゴやチェリーなど、赤い果実を思わせる香りが特徴です。

比較的軽やかなものから、ほどよい飲みごたえのあるものまで造られます。

最初に覚える一言：赤い果実の香りがある、軽やかで華やかな品種。

品種は「味わいのヒント」

ここで覚えた特徴は、あくまで入口です。

同じ品種でも、育つ場所や造り方によって、香りや飲みごたえは変わります。

品種のイメージだけで決めつけず、その商品の説明と合わせて覚えましょう。

7．主なワイン生産国を知る

ワインは、世界のさまざまな国で造られています。

最初は、私たちの料理にもつながるイタリア・スペインと、有名なワイン産地を多く持つフランスを入口にしましょう。

フランス

ボルドー、ブルゴーニュ、シャンパーニュなど、さまざまな有名産地があります。

イタリア

地域ごとのブドウ品種やワインが豊富で、多様なスタイルが造られています。

スペイン

赤・白に加え、スパークリングワインの「カヴァ」などでも知られています。

このほか、

ドイツ、ポルトガル、アメリカ、チリ、アルゼンチン、オーストラリア、ニュージーランド、南アフリカ、日本

なども、ワインを生産する国です。

最初からすべての国の特徴を暗記する必要はありません。

まずは、自分のお店のリストに載っている国から覚えていきましょう。

WINE BASIC

GOAL

ワインの種類に、「味わいの一言」を足せるようになる。

「白ワインです」だけでなく、

「柑橘のような香りがする、すっきりした辛口の白ワインです。」

「赤ワインです」だけでなく、

「果実の香りがあり、軽やかな味わいの赤ワインです。」

まずは、このくらいの説明からで大丈夫です。

分からないことは、無理に答えず、商品資料や先輩に確認しましょう。

大切なのは、難しい言葉をたくさん使うことではありません。

お客様が「それなら飲んでみたい」「自分の好みに合いそう」とイメージできる言葉で伝えることです。

次の「まず覚えるワイン10本」では、この基礎知識を実際の商品と結びつけて学んでいきましょう。
